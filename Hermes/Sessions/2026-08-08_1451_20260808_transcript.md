1. PHONE MANAGER APP (the big one — this is XOS's app killer, separate from Android settings)
   - Open the preinstalled "Phone Manager" app
   - Settings (gear icon, top-right) > Auto start (自动启动) > find Termux > turn ON
   - Same area: "Protected apps" / "App lock" — add Termux so the cleaner never touches it
   - Also check "Background app limit" — set it to "No limit" or ensure Termux is whitelisted

2. BATTERY (nested settings — XOS hides these deeper than stock)
   - Settings > Battery > ⋮ (three dots, top-right) > More battery settings
   - Toggle OFF "Auto clean" (自动清理) — this is the ROM-level app killer
   - Make sure "Smart power saving" / "Super power saving" is OFF
   - Settings > Apps > App management > Termux > Battery saver = "No restriction" (you may have set this, but confirm — XOS duplicates it here)

3. DEVELOPER OPTIONS (Android 15's own freezer — the exact toggle for the freeze you're seeing)
   - Settings > System > Developer options
   - Find "Suspend execution for cached apps" → toggle it OFF
   - If you can't find that exact label, look for "Freeze cached apps" / "内存冻结" — same thing
   - No developer options? Settings > About phone > tap "Build number" 7 times

4. OPTIONAL ADB COMMAND (most reliable if the toggle is hidden)
   From a PC: `adb shell settings put global cached_apps_freezer disabled`
   This disables the AOSP freezer outright. If XOS hides the developer toggle, this bypasses it.
