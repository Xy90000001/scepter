# Market Analysis Framework

> Use when evaluating a new market or validating demand for a product idea.

## Inputs Required
- Target customer segment (who, how many, where)
- Problem statement (what pain, how severe, frequency)
- Existing solutions (direct/indirect competitors, workarounds)
- Willingness to pay signals (searches, forums, surveys, pre-sales)

## Analysis Steps

|---|---|---|---|---|---|

### 3. Demand Validation
| Signal | Evidence | Confidence |
|---|---|---|
| Search volume (keywords) | | |
| Forum/Reddit complaints | | |
| Competitor traction (reviews, funding) | | |
| Pre-sales / waitlist signups | | |
| Cold outreach response rate | | |

### 4. Go/No-Go Criteria
- [ ] TAM > $X (your threshold)
- [ ] At least 3 validated pain points
- [ ] Clear differentiation vs. top 3 competitors
- [ ] Path to first 10 paying customers identified
- [ ] Unit economics viable at scale (LTV > 3x CAC)
