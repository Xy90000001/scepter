# MVP Scoping Framework

> Use to define the minimum viable product scope — what to build, what to defer.

## Inputs
- Validated problem (from market-analysis.md)
- Target user persona(s)
- Core value proposition (one sentence)
- Time/budget constraints

## Scoping Process

### 1. Core User Journey
Map the **one critical path** from problem → solution → value:
```
User has problem → Discovers product → Onboards → Achieves core outcome → Retains
```

### 2. Feature Classification
| Feature | Core Journey? | Differentiator? | Effort | Include in MVP? |
|---|---|---|---|---|

**Rules:**
- Only features on the core journey → MVP
- One differentiator feature → MVP (your "why us")
- Everything else → v1.1 backlog
