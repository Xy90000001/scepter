# Prioritization Framework

> Use to rank features, experiments, or initiatives objectively.

## Methods

### RICE (Reach × Impact × Confidence ÷ Effort)
| Initiative | Reach (users/mo) | Impact (1-5) | Confidence (%) | Effort (weeks) | RICE Score |
|---|---|---|---|---|---|

### ICE (Impact × Confidence × Ease)
| Initiative | Impact (1-10) | Confidence (1-10) | Ease (1-10) | ICE Score |
|---|---|---|---|---|

### Weighted Scoring (Custom)
| Criterion | Weight | Initiative A | Initiative B | Initiative C |
|---|---|---|---|---|
| Revenue impact | | | | |
| User retention | | | | |
| Strategic alignment | | | | |
| Technical debt reduction | | | | |
| Learning value | | | | |

## Process
1. List all candidates
2. Score using chosen method
3. Sort by score
4. Apply constraints (dependencies, sequencing, capacity)
5. Commit to top N for current cycle
